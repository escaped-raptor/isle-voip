How is the connection secured?
Testing without a certificate

Only certificates from publicly trusted certificate authorities are accepted, free or paid, the same ones web browsers trust. Self-signed certificates are refused. The server guide lists providers.

The server gets a free certificate from Let's Encrypt for your voice address and renews it by itself. To prove the address is yours, Let's Encrypt briefly connects to this server on port 80, so port 80 must be open to the internet now and at each renewal. Saving takes up to a minute.

Testing mode works on this computer only and does not prove who a player is. It is limited to 30 players, and only the SteamIDs you whitelist below can connect. Never use it for a public server. To leave it later, run setup again.

Keep 7777 if that is your game port: the game uses it over UDP and voice uses it over TCP, so they share the number. Players' clients assume this port unless you tell them another.
