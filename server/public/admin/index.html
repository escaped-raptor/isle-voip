Talk rules

Two players can talk only when both of their rules allow it, so nobody is heard by someone they can't hear back.

Hearing range

Players only hear each other when their dinosaurs are close together in the game. The game doesn't publish how far the F call carries, so the starting value of 100 metres is an estimate. To set it for your server, stand two players at the edge of where the F call can be heard and use "Measure a distance" on the Players page.

Voice groups

The game doesn't share its in-game groups, so players form a voice group in the client with a 6-letter code. Only species allowed to talk to each other can share a group.

Species

Each species follows its category's rule unless you give it its own.

Species check

Every player's species is checked when they join voice and again on a timer, so the rules still fit after a death or respawn.

Call key

      
The Isle has text chat only, and a dinosaur makes its F call when its player writes in it. This voice chat mimics that, so talking can be heard in the game. This keeps things fair: voice chat apps outside the game let players talk without making a sound in the game, which is an unfair stealth advantage. Push to talk is on F by default, so a player holding it to talk is already pressing the game's call key. For players who use voice activation or another talk key, their client can press the call key for them (F by default) when they start talking. Each player can rebind the key in their client to match their game.

      
      
This only allows it. In each player's client the call key press is off until they turn it on themselves, because it sends a key press into the game and has not been tested with The Isle's anti-cheat.
